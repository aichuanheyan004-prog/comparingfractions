How to Compare Fractions with the Same Numerator or Denominator

2026-08-064 min read

Use the shared part of the fractions to make a quick comparison, then confirm the result when signs or mixed numbers make it less obvious.

The direct answer

With the same positive denominator, the fraction with the larger numerator is larger. With the same positive numerator, the fraction with the smaller denominator is larger because each part is bigger.

Same denominator

Compare 3/8 and 5/8. Both wholes are divided into eight equal parts, so five parts is more than three parts: 5/8 > 3/8. No conversion is needed.

Same numerator

Compare 3/4 and 3/7. Three fourths uses larger pieces than three sevenths, so 3/4 > 3/7. This shortcut assumes positive denominators and the same positive numerator.

Use a visual check

Draw equal-length bars and divide each bar by its denominator. Shade the numerator parts. This makes the same-numerator rule easier to see: fewer divisions create larger pieces.

When the shortcut is not enough

Different numerators and denominators

For 5/12 and 3/7, cross-multiply: 5 × 7 = 35 and 3 × 12 = 36. Since 35 is smaller than 36, 5/12 < 3/7.

Negative fractions

Compare the positive magnitudes first, then remember that the value closer to zero is larger. For example, -3/4 < -3/7 because 3/4 is farther from zero.

Mixed numbers

Compare the whole-number parts first. If they match, compare the fractional parts. Converting both values to improper fractions is a useful check when the mixed-number parts are not obvious.

Quick practice

  • 7/9 versus 4/9: compare the numerators.
  • 2/5 versus 2/9: compare the size of the equal numerator parts.
  • 4/11 versus 3/8: cross-multiply and compare 32 with 33.
